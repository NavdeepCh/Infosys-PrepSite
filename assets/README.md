# 🎨 Assets

This folder contains static assets used by the application.

## Contents

- **favicon.png** - Website favicon and logo image

## Path References

When using assets in HTML, reference them as:
```html
<link rel="icon" type="image/png" href="./favicon.png">
<!-- or -->
<link rel="icon" type="image/png" href="./assets/favicon.png">
```

Vercel automatically serves files from the root, so both paths work.
